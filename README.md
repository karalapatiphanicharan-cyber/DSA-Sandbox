# DSA Sandbox 🚀

An advanced interactive Data Structures & Algorithms visualization platform built to make learning DSA intuitive, visual, and engaging.

🌐 Live Demo: https://dsa-sandbox-phi.vercel.app/

---

## 📖 Overview

DSA Sandbox is a modern web application that allows users to interact with popular data structures through real-time visualizations, animations, and step-by-step operations.

Instead of only reading theory, users can:

- Visualize data structures in real time
- Perform operations interactively
- Understand algorithm behavior visually
- Learn time and space complexity
- Explore practical applications
- Compare different structures

The project is designed for:

- Students learning DSA
- Interview preparation
- Educators and trainers
- Computer Science enthusiasts
- Portfolio demonstration

- Circular indexing
- Overflow detection

- Dynamic visualization

#### Deque
- Insert Front
- Insert Rear
- Delete Front
- Delete Rear

#### Priority Queue
- Priority-based insertion
- Removal by priority
- Dynamic ordering

#### Singly Linked List
- Insert Head
- Insert Tail
- Insert Position
- Delete Operations
- Traversal

#### Doubly Linked List
- Forward traversal
- Backward traversal
- Bidirectional links

#### Circular Linked List
- Circular node connection
- Continuous traversal

#### Binary Tree
- Node insertion
- Traversal visualization

- Insert

- Search

#### AVL Tree
- Self-balancing rotations

- Word insertion

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/karalapatiphanicharan-cyber/DSA-Sandbox.git
```

### Navigate

```bash
cd DSA-Sandbox
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```
