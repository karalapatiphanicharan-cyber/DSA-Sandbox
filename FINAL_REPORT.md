# DSA Sandbox: Final Project Report

## 1. Features Implemented
- **14 Data Structures**: Full visualization for Stacks, Queues (Circular, Deque, Priority), Linked Lists (Singly, Doubly, Circular), and Trees (BST, AVL, Red-Black, Heap, Trie).
- **Professional 3-Panel Layout**: Resizable sidebars for configuration and analysis.
- **Time Travel Debugger**: Full undo/redo/jump capability with state snapshots.
- **Real-time Code Generation**: Data-aware code snippets in Python, Java, JavaScript, and C++.
- **Performance Lab**: Interactive benchmarking engine with visual charts.
- **Interview Mode**: Quiz system for testing DSA knowledge.
- **Premium Design**: Neumorphism + Glassmorphism hybrid with Dark Mode support.
